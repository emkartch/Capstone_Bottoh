# 没頭 (bottou)
## Immersing Oneself In

![Logo of the game with a US passport and Japan passport on either side.](/img/TitlePage.png)

---

## Description

Our video game 没頭 (bottou) is an experience that uses its story and puzzles to grant the player the experience of full immersion in a country where you don’t speak the native language. This game involves the player exploring their environment and picking up context clues about Japanese in order to find their missing passport and win the game.

## Features/Usage

### Functionality

The game is a point-and-click; a user moves their mouse cursor to a specific screen location and presses a button to select, activate, or interact with an item. Players can press the return key to cycle through dialogue.

The inventory has a click-and-drag function and can open, close, and expand. The player can click and then drag an inventory item out to the center of the screen to make it bigger.

---

## Technology Used

For coding, we used **Godot Engine**, which is a free, open-source, and cross-platform game engine designed for creating both 2D and 3D games. 

For the art/animation, we used **Aesprite**, a dedicated 2D raster graphics editor designed specifically for creating pixel art and animated sprites, popular among game developers for 8-bit/16-bit styles. It features a specialized, efficient workflow with tools for layering, onion skinning, and frame-by-frame animation, including indexed color modes and pixel-perfect strokes.
